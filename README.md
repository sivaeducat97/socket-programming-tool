
# Socket Programming Tool Using Python

## Project Overview
A command-line networking tool developed using Python
socket programming.

## Features
1. TCP Port Scanner
2. Banner Grabber
3. TCP Client and Server
4. UDP Client and Server
5. Multi-client Chat Application

## Requirements
- Python 3
- Visual Studio Code or another Python editor

No external Python packages are required.

## How to Run
1. Install Python.
2. Open the project folder in a terminal.
3. Run:

   python Main.py

4. Select the required feature from the menu.
5. Follow the terminal instructions.

## Chat Commands
- /join - Check chat membership
- /msg <message> - Send a message to other clients
- /leave - Leave the chat

## Testing
All five features should be tested locally before submission.

## Security Notice
Use the scanner and banner grabber only on
localhost or systems you are authorized to test.

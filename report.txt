# LOCAL PRIVILEGE ESCALATION DETECTION TOOL

1. INTRODUCTION

---

The Local Privilege Escalation Detection Tool is a Python-based
Windows security auditing tool.

The purpose of this project is to identify potential security
misconfigurations and indicators that may be related to local
privilege escalation.

The tool performs detection and auditing only. It does not exploit
vulnerabilities or modify system security settings.

2. OBJECTIVES

---

The main objectives of this project are:

* Analyze current user privileges.
* Check file and directory permissions.
* Analyze running processes.
* Check selected Windows Registry settings.
* Analyze Windows Security event logs.

3. TECHNOLOGIES USED

---

Programming Language:
Python 3

Operating System:
Windows 10/11

Technologies:

* Windows Registry
* Windows Event Log
* Windows ACL permissions
* PowerShell
* Windows process information

4. MODULES

---

Module 1:
User Privilege Analysis

Module 2:
File and Directory Permission Analysis

Module 3:
Process Analysis

Module 4:
Registry Analysis

Module 5:
Windows Log Analysis

5. SECURITY CHECKS

---

The tool checks for:

* Administrator privileges
* Potentially broad file permissions
* Running process information
* UAC configuration
* AlwaysInstallElevated configuration
* Relevant Windows Security events

6. OUTPUT

---

The tool displays informational messages and warnings that can
be reviewed by a security administrator.

7. LIMITATIONS

---

This is a basic security auditing tool.

A warning does not automatically confirm that a vulnerability
exists.

All findings should be manually verified.

The tool does not exploit vulnerabilities.

8. CONCLUSION

---

This project demonstrates how Python can be used to perform
basic Windows security auditing and identify potential indicators
associated with local privilege escalation.

The project is intended for educational and defensive security
purposes.
